ABOUT SPLITSMART

A JavaScript project with a real product problem.

SplitSmart is designed as a Phase 1 mini project around the JavaScript syllabus: variables, arrays, higher-order functions, objects and JSON, DOM manipulation, events, form validation, LocalStorage and ES6 features.

What the project demonstrates

🧠

Business logic

Expenses become balances and balances become settlement instructions.

🧩

Modular JavaScript

Storage, UI, groups, expenses, settlement and analytics are separated into focused modules.

💾

Browser persistence

JSON data is serialized into LocalStorage, matching the Phase 1 browser-data-management topic.

Phase 1 boundary

No backend, database, API, payment gateway or cloud synchronization is required here. Those are natural Phase 2 directions rather than hidden dependencies.
